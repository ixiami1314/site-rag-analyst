Changelog

We ship every two weeks and publish the notable changes here. Enterprise workspaces receive release notes by email a day early.

v2.4.0 — March 2026

  • Flow Builder: full version history with side-by-side comparison and one-click rollback (up to 200 versions per flow).
  • Flow Builder: sub-flows — group blocks into reusable components.
  • Insights: anomaly alerts learn seasonal baselines.

v2.3.0 — January 2026

  • Webhooks: automatic retries with exponential backoff for 24 hours.
  • Connect: EDIFACT D96A message coverage extended with 12 new document types.
  • API: run timelines include step-level input/output snapshots for debugging.

v2.2.0 — October 2025

  • Insights: CSV and PDF export for every dashboard, plus scheduled exports to S3.
  • Connect: new connectors for Shopify and Microsoft Dynamics 365.
  • Mobile app: approval context cards now show document previews.

v2.1.0 — August 2025

  • Connect: SAP S/4HANA connector generally available.
  • Guard: SCIM directory sync for user provisioning.
  • Platform: EU data residency region (Frankfurt) for Enterprise workspaces.

v2.0.0 — March 2025

  • The new Flow Builder canvas with 120+ action blocks.
  • First version of the template library with 20 templates.

v1.9.2 — June 2025

  • Fix: EDIFACT D96A parsing of nested CIF segments with escaped quotes.
  • Fix: cursor pagination skipped records when page size hit exactly 200.

v1.9.0 — May 2025

  • Insights: SLA tracking with breach attribution per step.
  • Connect: DHL and Maersk carrier connectors.

v1.8.0 — April 2025

  • Template library v2 with example data and test mode.
  • Mobile app approvals (iOS first, Android in 1.8.1).
