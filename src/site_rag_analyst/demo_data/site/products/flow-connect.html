Flow Connect

Flow Connect is the integration layer of Meridian Flow. It links the systems your shipments already live in — ERPs, TMS platforms, customer portals, email inboxes — so flows read and write real data instead of re-typing it.

Prebuilt connectors

More than 80 prebuilt connectors ship with the platform, including SAP S/4HANA, Oracle NetSuite, Microsoft Dynamics 365, Shopify, and carrier APIs for DHL, Maersk and DSV. Each connector handles authentication, pagination and error semantics for you.

Legacy EDI support

Many forwarders still live on EDI. Flow Connect parses and emits EDIFACT and X12 documents natively — including D96A customs messages and 214 status updates — with a mapping language that translates between EDI segments and modern JSON fields.

Mapping language

When a prebuilt connector is not enough, the mapping language lets you describe transformations declaratively: field lookups, conditional splits, unit conversions, and reusable functions. Mappings are versioned and testable against sample documents before going live.

Webhooks and REST

Anything with an HTTP interface can join a flow. Outbound webhooks support HMAC signing and automatic retries with exponential backoff; inbound REST endpoints are generated per flow with OpenAPI schemas.

Connector lifecycle

Connectors version independently of the platform. When SAP ships a new API release, we certify the connector against it, publish it as a new minor version, and your workspace picks it up in a maintenance window you control. Deprecations are announced at least 90 days ahead with a migration note.

Security of connections

Credentials are stored in a hardware-backed vault, scoped per connector, and never appear in logs or exports. All traffic uses TLS 1.3; EU-resident workspaces keep connector traffic inside the Frankfurt region. Access to a connection can be restricted by role, so an operator can run a flow that reads SAP without ever seeing the service account behind it.

Email and spreadsheet ingestion

Two connectors do a surprising amount of work. The email connector turns a monitored inbox into a document source, parsing attachments (PDF, EDI, Excel) into structured fields. The spreadsheet connector watches a folder for CSV and XLSX files, maps columns with the mapping language, and refuses files that fail validation — sending a rejection notice back to the sender.
