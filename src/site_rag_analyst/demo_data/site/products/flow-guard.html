Flow Guard

Flow Guard is the security and compliance layer for Enterprise plans. It answers the questions auditors and security teams ask before a logistics platform can touch shipment data.

Single sign-on

Flow Guard supports SAML 2.0 and OIDC single sign-on, with just-in-time provisioning and SCIM directory sync. Enforce SSO for the whole workspace or only for roles with access to financial documents.

Role-based access control

Permissions attach to roles, not individuals: operator, approver, flow designer, auditor, administrator. Fine-grained scopes control who can view a document, edit a flow, or export data — and roles can be scoped per customer or per lane.

Tamper-evident audit logs

Every read, write, approval, export and administrative action is written to an append-only audit log. Log entries are hash-chained, making tampering evident, and retained for 7 years. Auditors can be given a read-only role with log search access and no access to document contents.

Certifications and data residency

Meridian Flow is SOC 2 Type II certified (audited annually by an independent firm) and ISO 27001 certified since 2023. Enterprise workspaces can pin data residency to the EU region, hosted in Frankfurt, with encryption at rest (AES-256) and in transit (TLS 1.3).

Data handling

Documents are encrypted at rest with AES-256 and in transit with TLS 1.3. Field-level policies can mask sensitive values (consignee tax ids, for example) from roles that do not need them — masked values never leave the platform through exports or the API for those roles.

Incident response

Guard subscribes your workspace to the platform incident feed: confirmed security incidents are reported to Enterprise admins within 24 hours, with a post-mortem within five business days. We run quarterly third-party penetration tests and publish the summary letter to Enterprise customers on request.

Bring your own key

Enterprise workspaces may supply their own encryption keys for document storage. Keys live in your KMS; the platform uses them via a delegation that you can revoke instantly, which immediately makes stored documents unreadable — by anyone, including us.
