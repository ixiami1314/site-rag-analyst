Flow Builder

Flow Builder is the visual workflow designer at the heart of Meridian Flow. Operators drag actions onto a canvas, connect them into routing rules, and publish flows without writing code — while engineers can drop into the mapping language whenever they need precision.

Canvas and action blocks

The canvas supports 120+ action blocks across eight categories: triggers, transforms, lookups, approvals, notifications, documents, connectors, and error handlers. Each block is configurable with expressions, and blocks can be grouped into reusable sub-flows.

Approvals where humans matter

Not everything should be automatic. Approval steps pause a flow and notify the right operator — by email or the mobile app — with a full context card and a two-tap approve or reject. Every decision is written to the audit log with the reviewer's identity and a timestamp.

Version history and rollback

Every published change creates an immutable version. Compare any two versions side by side, and roll back with one click — running shipments finish on the old version, new ones start on the restored version. Version history was introduced in version 2.0 of the platform and retains the last 200 versions per flow.

Template library

Start from 40+ templates maintained by our solutions team, covering customs declarations, booking confirmations, invoice reconciliation, and exception escalation. Templates are regular flows — clone and adapt them freely.

Expressions and conditions

Routing rules are expressions: lane equals 'UK', declared value above 50000 EUR, carrier response later than 4 hours. Expressions compose with and/or/not, and a linter flags ambiguous rules before publish. Power users can register custom functions per workspace — they run sandboxed and are versioned with the flow.

Testing and simulation

Every flow has a test mode: feed sample shipments through it and watch each branch fire. Simulation replays the last 30 days of real traffic against a draft version and reports what would have changed — new approvals raised, exceptions avoided, cycle-time deltas per lane — before anything ships.

Approvals on mobile

The Meridian Flow mobile app (iOS and Android) exists mostly for one thing: approvals. A push notification opens a context card with the document, the diff against the last version, and two buttons. Approving from the warehouse floor takes eleven seconds on average — we measured.

Guardrails

Flows have budgets: maximum runtime, maximum retries per step, and optional hard caps on documents processed per hour. A flow that exceeds its budget parks safely with a full snapshot for the operator instead of looping overnight.
