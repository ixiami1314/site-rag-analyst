Getting started

This guide takes you from an empty account to a running flow in about 15 minutes.

1. Create a workspace

Sign up with your work email and create a workspace. A workspace is the container for your team, flows and documents; most companies need exactly one. Workspaces are isolated from each other by default.

2. Invite your team

Invite teammates from the Members settings page with the roles they need: operator, approver, flow designer, auditor or administrator. New members get a guided tour on first login.

3. Connect a system

Head to Connectors and link one system — the CSV inbox is the fastest start, taking about two minutes. SAP S/4HANA and Oracle NetSuite connectors need service credentials from your IT team and usually take a day to commission.

4. Start from a template

Open the template library and clone a template close to your use case — for example "Customs declaration with approval". Templates arrive with example data and a test mode you can run against sample shipments.

5. Publish and watch

Publish the flow and watch the first shipment move through it on the run timeline. Set an SLA target and an alert channel, then invite your team to review cycle times in Insights after the first week.

What's next

Work through the template library, or read the API reference to call flows from your own systems.

Troubleshooting the first week

The three most common early stumbles: connectors with wrong service credentials (the connector page shows the exact scope a test call lacked), flows stuck in "waiting for approval" (someone was invited as operator instead of approver — fix roles in Members), and templates with example data still enabled (turn off test mode before publishing; the banner turns from amber to green).

Best practices

Name flows after the outcome, not the systems ("UK customs declaration", not "SAP-to-Portal sync"). Set an SLA target on day one even if you guess — it calibrates everyone. Review the exception reasons widget every Friday for a month; the top reason is usually one missing lookup that fixes a tenth of the exceptions at once.
